# 第五階段設計：送不送鹽，兩個結局

> 狀態：第五章、霧宿的建築與兩個結局已完成；霧宿裡的人還沒做。數字都是起始值，會用測試和實際遊玩調整。

## 一句話

鏽輪停下以後，鏽神的鹽塊在獵人手上：鏽錨站要它，霧裡另一個聲音叫你別送。送上去是結局「錨」，不送是結局「霧宿」。

## 為什麼這樣收

- 前四章一路埋下同一個問題：
  - 熄燈人說「燈一亮，他們就會送更多人來」；
  - 沉鐘說「這口鐘在告訴上面：這裡還有人活著」；
  - 推輪子的人說「鹽是給錨吃的，你送上去，他們會再放一個人下來接著推」。
- 第五章把這個問題交給獵人：繼續讓錨吃飽，還是讓它餓。
- 兩個結局都不是「好結局」：
  - 送鹽，站撐住了，但會有下一個人被放下來；
  - 不送，下面的人自由了，但站會沉。

## 第五章「錨」

第四章結束時，目標停在「等待鏽錨站的回音」。第五章從這裡接上。

### 目標

1. **聽無線電**：回到任何一座完整投放站的無線電，或補給艙的無線電。
   - 舵先開口：「鹽坊的輪子停了，站上感覺得到。把鏽神的鹽塊送回來，錨等不了太久。」
   - 雜訊裡插進另一個聲音，第3401號（第二座鹽塚下那塊編號牌的主人）：
     - 他沒有死，和其他沒有回去的獵人一起，在霧裡開了一間旅店；
     - 他說別把鹽送上去，帶到霧宿來；
     - 霧宿的位置會標在小地圖上。
2. **送，或不送**：同一個目標裡有兩條路，小地圖上兩個菱形。
   - 「把鹽塊放進回收艙」：任何一座完整投放站的無線電，和第一章交鹽的方式一樣。
   - 「把鹽塊帶到霧宿」：霧宿的爐火。
   - 先做的那一個決定這個世界的結局，之後另一條路就關上。
3. **結局**：播完結局的過場與故事卡，目標改成「故事結束」。世界繼續，可以照常玩。

### 結局「錨」：送上去

1. 鹽塊放進回收艙。這一次吊臂動了，艙升進霧裡。
2. 舵：「收到了。錨吃飽了，站還撐得住。……謝謝你，第3412號。」
3. 過場：
   - 很遠的地方，鏽錨站的鐘響了三下；
   - 又一個投放艙往下放；
   - 鹽坊那邊，大輪子又開始轉。
4. 故事卡：
   - 「站撐住了。」
   - 「第3413號醒來時，身邊是一座早就沒人用的投放站。」
   - 「結局　錨」

### 結局「霧宿」：不送

1. 鹽塊丟進霧宿的爐火，火變成藍色，冒出鹽燒的白煙。
2. 第3401號：「……留下來吧。這裡沒有錨。」
3. 當晚的過場：
   - 霧的那一頭，錨鍊響了很久，然後斷了；
   - 再也沒有鐘聲。
4. 故事卡：
   - 「那天以後，再也沒有投放艙落下來。」
   - 「霧沒有散，但霧宿的燈一直亮著。」
   - 「結局　霧宿」

## 霧宿

霧岸內陸、離鹽坊不遠的一間旅店。沒有回去的獵人在霧裡蓋的，用的是投放艙的殘骸和燈塔拆下來的木頭。

- **外觀**：兩層的木屋，屋頂鋪著投放艙的銅板，門口掛一盞一直亮著的燈。周圍有霧，但霧宿附近霧會淡一些。
- **裡面**：
  - 一樓是爐火、長桌和幾張床；
  - 牆上釘著很多編號牌，前三章撿到的三個號碼也在上面；
  - 二樓是儲物間，放著補給。
- **人**：
  - 第3401號，會說話，用站上職員那套對話畫面；
  - 另外兩三個沉默的獵人坐在桌邊。
  - 他們不打人，也不會被怪物當成目標。
- **金鐘**：門口有一口金鐘。
- **位置**：第一次走到第五章時才蓋，和霧鐘台、鹽坊一樣。
  - 鹽坊往海岸方向約三分之一處；
  - 平坦、乾燥、離其他地點夠遠；
  - 一般世界裡不會自然生成，只有故事模式有。

## 其他

- **多人**：結局是整個世界共用的。
  - 一個人做了選擇，其他人下次聽無線電或走近時，看到同一個結局的過場與故事卡。
  - 已經播過的不再播。
- **舊存檔**：停在第四章結尾、已經打倒鏽輪的獵人，下次進世界就接到第五章。
- **鹽塊弄丟了**：任何一塊鏽神的鹽塊都算，不一定要是鏽輪掉的那一塊。
- **成就**：兩個結局各一個，分別是「錨」與「霧宿」。
- **任務日誌**：記下走了哪一個結局，兩段結局的對白都收進無線電紀錄。
- **故事卡**：三張新圖，照前面幾張的像素畫風另外繪製：
  - 第五章開頭：無線電、鹽塊與霧中一盞燈；
  - 「錨」：一個艙升起、另一個艙放下，遠處的輪子；
  - 「霧宿」：霧中亮著燈的霧宿，窗裡藍色的爐火。
- **過場的其他部分**用對白與聲音帶過：「錨」是遠處的三下鐘聲，「霧宿」是錨鍊長長的聲響和斷掉的聲音。

## 技術作法

- **故事步驟**：
  - 新增 `CALL`（聽無線電）與 `CHOOSE`（送或不送），屬於第五章；
  - 結局一個 `ENDED` 步驟；
  - 走了哪一個結局另外記在世界上（`StoryEnding`：無、錨、霧宿）。
  - 第四章的 `WAIT` 改成接到第五章。
- **地點**：`StoryInn` 記錄霧宿的位置與爐火，在第一次進第五章時蓋，和 `StoryWorks` 一樣。
- **送鹽**：沿用第一章的 `StoryService.deliver`，在第五章時改走結局「錨」，回收艙這次會升起（吊臂的動畫已經有）。
- **爐火**：對霧宿的爐火拿著鹽塊按右鍵，走結局「霧宿」。
- **第二個聲音**：無線電的對白序列可以混不同的說話者（前面幾章已經這樣做），第3401號加一個說話者。
- **測試**：`MistinnStoryTest` 接著第四章往下玩兩次：
  - 一次送鹽，一次不送，各在不同的世界；
  - 檢查兩個結局的目標、過場、故事卡、成就與日誌；
  - 檢查結局之後另一條路不再有反應。

## 實作順序

1. 故事步驟、結局的記錄、第五章的無線電與兩條路（不含霧宿的建築，先用一個標記點）。
2. 霧宿的建築與裡面的人。
3. 兩個結局的過場、故事卡與成就。
4. README 與手冊。
