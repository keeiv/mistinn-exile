# 第三階段設計：沉鐘與霧鐘台

> 狀態：實作中。數字都是起始值，會用測試和實際遊玩調整。

## 一句話

霧岸外的礁石上，立著一座半沉的霧鐘台。從前起霧時，這裡敲鐘替船指路；如今敲鐘的是沉鐘，每敲一聲，霧就濃一層。

## 為什麼是沉鐘

- 熄燈人把「黑暗」做成壓力，玩家可以點燈台去處理。沉鐘把「霧」做成壓力，玩家要靠打它的鐘來處理。
- 熄燈人高瘦靈活，會跳、會鉤、會滑；沉鐘矮壯沉重，靠範圍和節奏壓人。兩場戰鬥要的是不同的手感。
- 它從鏽錨站延伸而來：站上的鐘在投放時響三下，霧鐘台的鐘是同一種聲音。鐘婆認得這個聲音，但不說。

## 實作順序

1. **燈守的共用骨架**（已完成）：熄燈人的血條、招式執行、大腦、失衡與重擊累計抽成共用的燈守基底，沉鐘和之後的鏽輪共用。行為不變。
2. **沉鐘本體**（已完成）：模型、招式、霧層、反鳴、失衡、裂鐘的雙響。
3. **霧鐘台**（已完成）：結構、世界生成、霧岸的霧、金鐘、補給、掉落、成就、手冊。
4. **之後**：專屬掉落、故事模式的章節。鐘樓的霧牆與罩鐘已完成。

## 沉鐘

溺死的敲鐘人。肩膀以上罩在一口裂開的銅鐘裡，鐘面長滿銅綠和藤壺；身上纏著海草和錨鍊，雙手握著鐘的鐘舌，一顆拴著鍊子的大鐵錘。比熄燈人矮，卻寬得多，走路像在涉水。

|---|---|
| 生命 | 360 |
| 護甲 | 10 |
| 擊退抗性 | 1.0（推不動） |
| 掉落 | 鏽神的鹽塊 ×1、鹽 3500、30% 機率掉一件品級 III～IV 的裝備 |

### 霧層

- **鐘響**：沉鐘用鐘舌敲自己的鐘，一圈聲波沿著地面往外滾（約 0.6 秒從 2 格擴到 11 格）。聲波經過時站在地上的獵人頭部受擊，跳起來或翻滾就能躲過。
- **每響一聲霧就濃一層**，最多四層。房裡看得到的距離：無霧 24 格 → 16 → 11 → 7 → 4.5 格。小地圖跟著縮。
- 15 秒沒有鐘響，霧就散一層。
- **夜裡的鐘聲**：沒有獵人時，沉鐘在夜裡每隔半分鐘到一分多鐘會自己敲一下鐘，聲音傳得很遠，但不起霧、不打人。在霧裡迷路的獵人可以循聲找到霧鐘台。
- **深響**：霧到第四層時，沉鐘把鐘舌高舉過頂，接連敲三下，三圈聲波一圈比一圈遠。之後霧退回一層。
- 霧再濃，招式的預兆都有聲音：鐘響之前鐘會先嗡鳴，看不見也聽得到。

### 反鳴

- 蓄滿的重擊打中沉鐘，會敲響它自己的鐘：霧散一層。
- 連續三記、每記相隔不到十秒，它會**失衡**五秒（受到的傷害 ×1.5），霧再散兩層。已經失衡時再打不累計。
- **為什麼這樣設計**：霧是它的武器，鐘是它的弱點。玩家越敢貼近重擊，視野就越清楚。

### 第一階段（100%～50%）

| 招式 | 預兆 | 打哪裡 |
|---|---|---|
| 鐘響 | 雙手把鐘舌舉到鐘邊，鐘先嗡鳴 | 聲波沿地面擴散，頭部 |
| 鐘舌橫掃 | 身體往右扭，鐘舌甩到身後 | 前方大扇形，軀幹或手 |
| 鐘舌砸 | 鐘舌高舉過頭 | 正前方一條，頭部 |
| 頂鐘衝撞 | 低頭，腳在地上刨兩下 | 往前衝七格，軀幹 |
| 鍊甩 | 鐘舌在身側甩圈 | 貼地往前甩九格，雙腿 |
| 回潮 | 腳下的水往它那裡流 | 把 10 格內的獵人拖近，接著繞身一圈，軀幹 |
| 側步、後撤 | 沉重的涉水聲 | 不打人 |
| 假鐘響 | 和鐘響一模一樣的舉錘 | 不敲，轉成橫掃或衝撞 |
| 鐘鳴（信號） | 鐘自己低聲嗡鳴 | 接下來一定是鐘響類 |

### 第二階段（50% 以下）：裂鐘

- 鐘裂開一道縫，鐘響變成**雙響**：第二圈聲波緊跟著第一圈。
- 霧散得比較慢（20 秒一層）。
- **罩鐘**（已完成）：蹲低後跳起來，把鐘罩到獵人頭上，罩住的人看不見也動不了，裡面再敲一響；落地前翻滾離開就躲得掉。

## 霧鐘台

- **生成**：主世界淺海、離海岸不遠的礁石上，或海灘的水邊，和燈塔差不多少見（用地形探測量過：同樣大的範圍裡，霧鐘台約 0.6 座、燈塔約 0.4 座）。和燈塔一樣會被記下來，周圍起霧岸的霧。
- **結構**：
  1. **礁石與棧橋**：上岸的地方有一座金鐘石龕。
  2. **台身**：三層的方石塔，底層半淹在水裡，樓梯沿牆往上。補給和燈塔一樣分三層：底層的木桶、二樓的箱子、鐘樓裡沉鐘身後的箱子。
  3. **鐘樓（頭目房）**：頂上是露天的圓形平台，半徑約 8 格，從塔牆往外伸出去，四根柱子撐著銅綠的屋頂，中央吊著一口巨大的鐘。沉鐘站在鐘下，樓梯的出口就在它身邊。
- **霧牆**（已完成）：和燈室一樣，獵人上到鐘樓，霧就封住樓梯口，直到沉鐘倒下或房裡沒有獵人。

## 技術作法

- **共用骨架**：`keeper/Keeper` 放血條、`MoveRunner`、`BossBrain`、招式同步、失衡與重擊累計。熄燈人和沉鐘各自只寫自己的招式與規則。原本特別排除熄燈人的地方（噪音、踉蹌、滑鏟、重擊）改成排除所有燈守。
- **招式**：沿用 `BossMove` 和大腦。沉鐘的動作片段放在 `anim/bell/`，和熄燈人的 `anim/keeper/` 分開。
- **霧層**：伺服器端記層數並同步給客戶端，客戶端在霧岸的霧上再加厚，小地圖讀同一個值。
- **模型**：在 Blockbench 建模，貼圖照 UV 範本另外繪製。
- **音效**：專案合成的鐘聲、水聲，加上已有的鍊條聲，來源記在 CREDITS。
- **測試**：每個招式都有動作片段與預兆音效；聲波只打地上的人、跳起來躲得過；霧層會增加、會散、會被重擊敲掉；三記重擊失衡；結構裡有鐘樓、金鐘與補給。
